Web Browsers and Web Servers

A web browser is a client application that requests resources and presents them to a user. A web server is software that listens for requests and returns responses. “Server” can also refer to the computer or virtual machine running that software. A browser rendering engine (such as Gecko, Blink, or WebKit) displays the page; a JavaScript engine executes scripts. A server such as Apache or Nginx handles HTTP connections and often works with application runtimes such as PHP, Python, or Node.js.
