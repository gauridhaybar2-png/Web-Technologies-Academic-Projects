Events and Buttons

An event is something that happens in the browser, such as a click, key press, form submission, or page load. An event listener connects an event to a function. Prefer addEventListener() so behavior remains separate from HTML structure and several listeners can be attached without mixing logic into inline markup. This separation is a key principle of maintainable front-end code.

When a user interacts with the page, the browser creates an event object that contains useful information such as which element was clicked and what type of event occurred. Developers can inspect that object to decide how to respond. This is the foundation for features such as form validation, drag-and-drop interfaces, button-based actions, keyboard shortcuts, and interactive charts.

click

Button activation, including keyboard activation for native buttons.

input

Fires as a user edits an input value and is useful for real-time validation.

submit

Fires when a form is submitted; useful for validation and handling.

Event object

Provides details about the event and the element that received it, enabling targeted behavior.
