Introduction to jQuery

jQuery is a JavaScript library that offers concise APIs for selecting elements, handling events, updating the DOM, effects, and AJAX. It was especially valuable when browser differences required extra compatibility work. Modern browsers provide many equivalent capabilities directly, but jQuery remains in existing projects and is useful to recognize because many older codebases still use it and many students need to read it when maintaining legacy websites.

The main advantage of jQuery is readability and shorter code. Instead of writing several DOM API calls, a developer can select an element with a CSS-style expression and change its content or classes in a single chained statement. It also simplified event-driven programming and AJAX by providing consistent behavior across browsers at a time when JavaScript support varied significantly.

Select elements

$(".notice") selects elements using familiar CSS selector syntax.

Wait for the DOM

$(function () { ... }) runs after the document is ready to be manipulated.

Handle events

.on("click", handler) attaches an event listener.

Update content

Methods such as .text() , .addClass() , and .toggleClass() manipulate selected elements.
