HTML5:Multimedia,Input Types and API's

Native support for rich media,eliminating the need for legacy browser plugins.

Native Benefits

  • Standardized Playback:
    • HTML5 introduces first-class media elements that run natively inside browsers without external software.
  • No Third-Party Plugins:
    • Eliminates security risks and overhead associated with tools like Adobe Flash.
  • Direct Page Embedding:
    • Embed media assets directly into the markup for better performance and DOM control.

Implementation

HTML5: Multimedia, Input Types, and APIs (Contd.)

The <audio> element brings native, plugin-free audio streaming directly to the web browser.

The <audio> Element

HTML Source:

<audio controls>
  <source src="podcast.mp3" type="audio/mpeg">
</audio>

Specify multiple sources using the nested source tag to support different audio formats like MP3, WAV, or OGG across various browsers.

Control & Behavior

Key Attributes

  • controls:
    • Adds essential user play, pause, and volume controls to the interface.
  • autoplay:
    • Instructs the browser to start playing the audio file automatically.
  • loop:
    • Restarts the audio sequence automatically from the beginning when done.
  • muted:
    • Loads and begins playing the audio with the volume initially turned off.

New Form Input Types

HTML5 forms introduce built-in validation and native mobile keyboards.

Smarter Forms

HTML5 made forms much smarter. Browsers now provide built-in validation and specialized mobile keyboards without needing complex JavaScript.

Native Browser Power

  • email <input type="email">
  • Validates that the input contains an @ symbol.
  • date <input type="date">
  • Opens a native pop-up calendar to pick a date.
  • color <input type="color">

The Drag and Drop API

HTML5 allows natively dragging elements using simple attributes and standard JavaScript events.

Native Attribute

Making Elements Draggable

By default, only images, links, and text selections are draggable. To make any other HTML element draggable, add the native attribute:

draggable="true"

  • Applies to standard containers like <div>, <p>, and custom elements.

JavaScript Events

Key Drag & Drop Events

  • ondragstart:
    • Triggers immediately when the user clicks and begins dragging the element.
  • ondragover:
    • Specifies where dragged elements can be dropped. Must prevent default browser blocking to allow drops.
  • ondrop:
    • Executes custom drop logic when the draggable element is finally released.
