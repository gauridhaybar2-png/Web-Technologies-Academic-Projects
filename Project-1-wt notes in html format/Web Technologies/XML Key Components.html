XML Key Components

An XML document is a tree of nodes. The following example includes the most common pieces: a declaration, a root element, nested elements, attributes, text, and a comment.

XML syntax rules to remember

Element names are case-sensitive: and are different names.
Every opened element must be closed, or be empty-element syntax such as .
Elements must be properly nested; ... is not well-formed.
There must be exactly one document element (root), though it may contain many children.
Reserved characters in text must be escaped: use & , < , and > for ampersand, less- than, and greater-than.

Namespaces

Namespaces prevent naming collisions when XML from different vocabularies is combined. A namespace prefix is connected to a URI by xmlns ; the URI identifies the vocabulary and does not have to be a working web page.
