CSS Syntax and Selectors

A CSS rule has a selector followed by a declaration block. Each declaration pairs a property with a value.

CSS Values, Units, and Custom Properties

A property only has an effect when it receives a value valid for that property. Values may be keywords such as auto , colors, numbers, lengths, percentages, or functions. A length usually needs a unit: 16px is a fixed CSS-pixel length, while relative units can adapt to text or the available space.

Custom properties, often called CSS variables, store reusable values. Names begin with two hyphens and are read with var() . Defining shared colors or spacing on :root makes them available throughout the document and easier to update consistently.

How the Cascade Chooses a Value

If several rules set the same property, the browser resolves the cascade by importance and origin, selector specificity, and then source order. The later rule wins only when the earlier comparisons are tied. Inline styles commonly outrank normal stylesheet rules but are not an unconditional highest priority.

Inheritance and the Cascade

Some properties, especially text-related properties such as color and font- family , are inherited: a child can use the computed value of its parent when it has no value of its own. Many layout and box properties, such as margin , padding , and border , do not inherit by default. Inheritance is separate from specificity: the cascade first determines the value on an element, and inheritance can supply a value to a child when needed.
