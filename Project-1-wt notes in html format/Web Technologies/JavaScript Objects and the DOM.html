JavaScript Objects and the DOM

Objects group related data and behavior. The Document Object Model (DOM) represents an HTML document as a tree of nodes. JavaScript can find nodes, read or change their content, update attributes and classes, and create new elements. This is the heart of dynamic web pages: instead of static text, the browser script can modify a heading, change a button label, inject content into a list, or highlight a card after an action.

In MDN terms, an object is a collection of related properties and methods. For example, a student object can contain properties such as name , rollNo , and department , along with methods like displayInfo() . The DOM is a browser- created object model that exposes every HTML element as a JavaScript object. Because the DOM is a tree, JavaScript can traverse from a parent node to child nodes, update specific elements, and react to user events.

In real websites, the DOM is what lets the page respond to the user without reloading. A login form may check that the password field is valid, a shopping cart might update totals after a quantity change, and a dashboard may replace a chart when a user selects a different period. JavaScript uses object properties, method calls, and selector APIs to work with these elements.
