HTML Lists

HTML lists allow web developers to group a set of related items into organized structures.

Unordered HTML List

Defines a bulleted list where the order of items does not explicitly matter.

<ul>
<li>Coffee</li>
<li>Tea</li>
<li>Milk</li>
</ul>
  • Coffee
  • Tea
  • Milk

Ordered HTML List

Defines an ordered list where list items are marked with numbers by default.

<ol>
<li>Coffee</li>
<li>Tea</li>
<li>Milk</li>
</ol>
  1. Coffee
  2. Tea
  3. Milk

HTML Description Lists

Defines a description list of terms with their corresponding descriptions.

The List Structure

<dl>
<dt>Coffee</dt>
<dd>- black hot drink</dd>
<dt>Milk</dt>
<dd>- white cold drink</dd>
</dl>

Browser Output

Coffee
- black hot drink
Milk
- white cold drink

HTML List Tags

A quick reference guide to unordered, ordered, and description list elements in HTML.

Standard Lists

  • <ul> Defines an unordered (bulleted) list.
  • <ol> Defines an ordered (numbered) list.
  • <li> Defines a list item within a list.

Key-Value Pairs

  • <dl> Defines a complete description list.
  • <dt> Defines a term within the description list.
  • <dd> Provides the description for the term.

HTML Tables

HTML tables allow web developers to arrange data into rows and columns.

Table Structure

  • <table> The wrapper element that defines the entire table.
  • <tr> Defines a table row container for cells.
  • <th> Defines a header cell, bold and centered by default.
  • <td> Defines a standard table data cell.

HTML Source Code

<table>
<tr>
<th>Company</th>
<th>Contact</th>
</tr>
<tr>
<td>Alfreds Futterkiste</td>
<td>Maria Anders</td>
</tr>
</table>

Define an HTML Table

A table in HTML consists of table cells organized inside systematic rows and columns.

Table Components

  • <table> The primary wrapper container element.
  • <tr> Defines a table row containing individual cells.
  • <th> Defines bold and centered header cells.
  • <td> Defines standard data cells.

HTML Implementation

<table border="1">
<tr>
<th>Company</th>
<th>Contact</th>
<th>Country</th>
</tr>
<tr>
<td>Alfreds Futterkiste</td>
<td>Maria Anders</td>
<td>Germany</td>
</tr>
<tr>
<td>Centro comercial Moctezuma</td>
<td>Francisco Chang</td>
<td>Mexico</td>
</tr>
</table>

Table Cells

HTML table cells are defined using the <td> element to house and structure diverse data types.

Cell Definition & Rules

  • The <td> Element:
    • Each table cell is defined by an opening <td> and closing </td> tag.
  • Meaning:
    • td stands for Table Data, which holds the actual content.
  • Content:
    • Everything between the tags is treated as cell content.

A table cell can contain text, images, lists, links, or even nested tables.

Implementation & Preview

<table border="1">
<tr>
<td>Emil</td>
<td>Tobias</td>
<td>Linus</td>
</tr>
</table>
Emil Tobias Linus

Table Rows

HTML table rows are defined using the <tr> element to group and structure cell data horizontally.

Row Definition & Rules

  • The <tr> Element:
    • Each table row starts with an opening <tr> and ends with a </tr> tag.
  • Meaning:
    • tr stands for Table Row.
  • Rows:
    • You can have as many rows as you like; just ensure the number of cells is consistent.

Implementation & Preview

<table border="1">
<tr>
<td>Emil</td>
<td>Tobias</td>
<td>Linus</td>
</tr>
<tr>
<td>16</td>
<td>14</td>
<td>10</td>
</tr>
</table>

Table Headers

Use the <th> tag instead of the <td> tag to define table header cells with bold and centered text by default.

Header Definition & Rules

  • The <th> Element:
    • Each header cell is defined by an opening <th> and closing </th> tag.
  • Meaning:
    • th stands for Table Header.
  • Default Style:
    • Browsers display text in header cells as bold and centered.

Implementation & Preview

<table border="1">
<tr>
<th>Person 1</th>
<th>Person 2</th>
</tr>
<tr>
<td>Emil</td>
<td>Tobias</td>
</tr>
</table>

HTML Images

Embedding visual media, defining alternative descriptions, and setting dimensions.

Syntax & Structure

The <img> element is used to embed an image in a web page.

  • src specifies the path or URL to the image file.
  • alt specifies alternate text for screen readers or broken links.
  • The <img> element is empty and has no closing tag.

HTML Source Code

<img src="pic_trulli.jpg" alt="Italian Trulli">

The src Attribute

Understanding how web browsers resolve, fetch, and display image paths dynamically.

Attribute Role

  • Path Resolution:
    • The required src attribute specifies the precise URL or directory path to the target image resource.
  • Page Loading:
    • When a page loads, the browser gets the image from the server and inserts it into the viewport.
  • File Location:
    • Keep image files in consistent locations to prevent broken link icons from displaying alongside the alt text.

Example Implementation

<img src="img_chania.jpg" alt="Flowers in Chania">

The alt Attribute

Ensure accessibility and graceful degradation when images fail to render.

Attribute Purpose

  • Fallback Text:
    • The required alt attribute provides fallback text when an image cannot be viewed.
  • Accessibility:
    • Essential for users with slow connections, broken image sources, or assistive technologies.
  • Description:
    • The value should descriptively and accurately convey the image content.

Syntax

<img src="img_chania.jpg" alt="Flowers in Chania">

Image Size - Width and Height

Learn how to specify image dimensions using styles or attributes to prevent layout shifts.

Sizing Methods

  • The style attribute defines inline CSS dimensions.
  • Alternatively, native width and height attributes define size in pixels.
  • Best Practice: Always specify size. Without it, pages may flicker or shift layouts while images load.

Syntax Examples

<img src="img_girl.jpg"
style="width:500px;height:600px;">

<img src="img_girl.jpg"
width="500" height="600">

The < form > Element

The primary container used to structure and gather user inputs.

Input Container

The <form> element is a dedicated container designed to house and coordinate multiple user input components.

  • Text Fields & Areas for descriptive text input
  • Checkboxes & Radios for selection options
  • Submit Buttons to process and dispatch data

Basic Syntax

<form>
...
form elements
...
</form>

The < input > Element

The most versatile and frequently used component within HTML forms.

Dynamic & Adaptable

An <input> element can be displayed in many ways, depending on the value of its type attribute.

Common Type Attributes

  • type="text" Displays a single-line text input field.
  • type="radio" Displays a radio button for selecting one option.
  • type="checkbox" Displays a checkbox for multiple choices.
  • type="submit" Displays a button to submit form data to a server.

Text Fields

The <input type="text"> defines a single-line input field for user text input.

HTML Form Syntax

<form>
<label for="fname">First name:</label><br>
<input type="text" id="fname" name="fname"><br>
<label for="lname">Last name:</label><br>
<input type="text" id="lname" name="lname">
</form>

The < label > Element

Enhancing web accessibility, user experience, and semantic form connections.

Screen Readers

A screen-reader will read the label out loud when a user focuses on the input element, making forms highly accessible.

Explicit Binding

The for attribute of the label must match the id of the target input element to bind them together.

HTML5 Semantic Elements

Essential semantic elements for structuring modern, accessible web layouts.

Layout Semantic Tags

  • <header> Defines the introduction and bottom metadata of the page or section.
  • <nav> Declares a block of navigation links for website traversal.
  • <main> Identifies the primary content of the document.
  • <footer> Defines the page bottom section.

Content & Sections

  • <section> A thematic grouping of content, typically starting with its own heading.
  • <article> Represents independent, self-contained content.
  • <aside> Contains content indirectly related to the main content, often as a sidebar.

Semantic HTML - Key Benefits

SEO

Helps search engines and crawlers index and understand page layout and content structure efficiently.

Accessibility

Enables screen readers to easily navigate and translate the structure for visually impaired users.

Code Readability

Improves the developer experience with clean, intuitive, and highly organized source code structure.
