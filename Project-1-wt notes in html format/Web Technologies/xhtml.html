XHTML: Meta Tags

An essential guide to document metadata, indexing, and character encoding in XHTML.

XHTML and Meta Tags

While HTML5 is forgiving (it doesn't crash if you forget to close a tag), XHTML is the strict, XML-based version of HTML.

Strict Standard

Unlike HTML5, XHTML does not tolerate syntax shortcuts. By enforcing XML conformance, it ensures your code remains consistent, clean, and easily parsed by automated tools and enterprise systems.

The Core Rules of XHTML

  • 1. Strictly Lowercase Tags:
    • All tags must be lowercase. Use <body>, never <BODY>.
  • 2. Properly Closed Elements:
    • Empty elements must include a closing slash: <br /> instead of <br>.
  • 3. Perfect Nesting Hierarchy:
    • Tags must be nested in precise order: <b><i>bold italic</i></b>.

Meta Tags

Provide essential metadata to browsers, search engines, and web services inside the <head> element.

Document Head

Invisible Metadata

Meta tags reside exclusively in the HTML header. While invisible to visitors, they communicate critical configuration, SEO, and viewport behavior to machines.

HTML Source:

<head>
  <meta ...>
  <title>My Page</title>
</head>

Types of Meta Tags

  • charset <meta charset="UTF-8">
    • Defines character encoding and ensures emojis and accents render correctly.
  • viewport <meta name="viewport" content="...">
    • Enables responsive web design by scaling pages for mobile screens.
  • description <meta name="description" content="...">
    • Provides page summary used directly by Google in search results.
  • author <meta name="author" content="Your Name">
    • Specifies the author of the document.
  • refresh <meta http-equiv="refresh" content="30">
    • Refreshes the page automatically every 30 seconds.
