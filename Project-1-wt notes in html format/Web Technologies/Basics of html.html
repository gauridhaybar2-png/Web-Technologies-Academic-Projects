What is HTML?

The Standard

  • HTML stands for Hyper Text Markup Language.
  • It is the standard markup language for creating Web Pages.

Structure & Elements

  • Describes the Visual Structure of a web page
  • Consists of series of nested elements that define layout blocks

Browser Rendering

  • Tells the browser exactly how to display the content.
  • Labels pieces of content such as headings, paragraphs and links.

Nested HTML Elements

HTML elements can be nested,meaning they can contain other elements.

Nesting Principles

  • All HTML documents consist of nested HTML elements that build the document structure.
  • Nesting means that HTML elements can contain other elements inside them.
  • Always ensure tags are closed in the correct reverse order of their opening.

The HTML Document Root

  • The < html > element is the root elementand it defines the entire HTML document.
  • It strictly consists of a start tag < html > and an end tag < /html >
  • Inside the root container, the < body > element encloses all visible page contents.

The < body > element

Defines the document's body.It encloses all visible page content,containing other elements like headings and paragraphs.

The < h1 > Element

Defines a prominent heading.Always pair the start tag and end tag to establish proper semantic hierarchy.

The < p > Element

Defines a standard paragraphs of body text.It automatically ontroduces vertical nargins before and after the block.

Never Skip the End tag

Relying on automatic tag closure can lead to unpredictable layout rendering and validatio errors.

Browser Tolerance VS Standards

  • Some HTML elements may still display correctly in the browser even if you accidently omit the closing tag.
  • This happens because browser engines attempt to perform automatic error correction on malformed markup.
  • Never rely on this behaviour! Unexpected rendering bugs,style leakage and accessibility issues will occur if you forget the end tag.

Flawed Code Example

                    < html >
                        < body >
                        < p >This is a paragraph   < !--Missing end tag-- >
                        < p > This is a paragraph  < !--Missing end tag-- >
                        < /body >
                    < /html >

Empty HTML Elements

Understanding HTML tags that contain no content and do not require closing tags.

What are Empty Elements

  • HTML elements with no content are called empty elements.
  • The < br> tag defines a line break , and is a classic example of an empty element.
  • Empty elements do not have a closing tag.

HTML Documents

The fundamental rules and visual structure of every web page

Structure Rules

  • All HTML documents must start with a document type declaration:
    < !DOCTYPE >
  • The HTML document itself begins with< html > and ends with
    < /html >
  • The visible part of the document is nested between < body > and < /body >

The < !DOCTYPE > Declaration

Informs the web browser about the document type to ensure correct and consistent page rendering.

Declaration Rules

  • Represents the document type and helps web browser to dispaly pages correctly.
  • Must appear only once , at the very top of the page(before any HTML tags).
  • The declaration is not case sensitive
  • The modern standard for HTML5 is < !DOCTYPE html >

HTML Headings

Defining semantic and visual hierarchy to structure web page content.

Heading Rules

  • HTML headings are defined with the < h1 > to < h6 > tags.
  • < h1 > defines the most important heading(highest visual weight).
  • < h6 > defines the least important heading(lowest visual weight).

HTML Paragraphs

Defining block level text elements to structure written content on a web page

Paragraph Rules

  • HTML Paragraphs are defined with the < p >tag.

  • They are block level elements,meaning they always start on a new line.
  • Browsers automatically add some white space(margin) before and after a paragraph.

HTML Links

Defining hyperlinks to connect web pages and navigate to external resources.

Link Rules

  • HTML links are defined with the < a > tag.
  • The links destination is specified in the href attribute.
  • Attributes are used to provide additional information about HTML elements.

HTML Images

Embedding visual media,defining alternative descriptions and setting dimensions.

Image Rules

  • HTML images are defined with the < img >tag.
  • Attributes like src(source),alt(alternative text),width and height configure the image properties.

How to view HTML Source

Explore , analyze and experiment with the underlying code of any web page in real time.

View Page Source

Perfect for viewing the entire,original raw HTML document in a static,read only view.

  • Press CTRL+U(Windows) or Cmd+Option+U(Mac)
  • Alternatively,right click anywhere on the page and select "View Page Source".
  • This action opens a brand new browser tab containing the complete source code.

Inspect HTML Elements

Best for examining , styling and debugging individual elements interactively.

  • Right click directly on any specific element and choose "Inspect"
  • The DevTools panel will open,highlighting both the live HTML structure and associated CSS styles.
  • You can temporarily edit text,swap classes or change the colore on the fly to test layouts.

HTML is Not A Case Sensitive

Understanding tag standards,recommendations and instituitional rules.

W3C standards and Behavior

  • HTML tags are not case sensitive:< P > means the same as < p >

  • W3C demands lowercase for stricter document types like XHTML.

HTML Attributes

Key concepts,specifications and standard syntax rules for element properties

Core Behavior

  • All HTML elements can have attributes,which modify default element behavior or styling.
  • Attributes provide vital additional information about elements , such as source paths or link destinations.

Syntax Rules

  • Attributes are always specified in the start tag , never in the end tag.
  • Attributes usually come in name/value pairs like:name="value".

The href attribute

Defining hyperlinks and directing navigation paths in HTML documents.

Core Purpose

  • The < a > tag(anchor tag) defines a hyperlink, allowing users to navigate from one page to another.
  • The href attribute is critical-it specifies the destination URL or pathof the linked pages.

Syntax & Example

A standard anchor element pointing to an external website destination:
< a href ="https://www.itmbu.ac.in" >Click here< /a >

The src attribute

Embedding images and managing paths in HTML documents

Core Behavior

The < img > tag embeds an image in a page . The src attribute defines the image path.
Syntax Example:
< img src="img.png" >

URL Specifications

  1. Absolute URL:Links to external sites.
    Example:src="[link removed]"
    Subject to copyright and external deletion.
  2. Relative URL:Hosted within the website.
    Example:src="img.jpg"
    Recommended .Won't break if domain changes.

The width and height Attributes

Specifying exact dimensions and reserving layout space for images.

Core Purpose

  • The width and height attribute specify the dimensions of the image in pixels.
  • Defining these attributes prevents page layout flicker and shift while the image is loading.

Syntax &Example

A standard image element with defined pixel width and height:
< img src="img.png" height="600" width="500" >

The alt attribute

Providing alternate descriptions for accessibility and fallback display.

Core Purpose

  • Fallback Text: Specifies an alternate description if the image cannot be loaded or displayed.
  • Accessibility:Crucial for screen readers used by visually impaired users to understand page content.
  • Resilience:Displays when users have slow connections or if the image source path is broken.

Syntax & Example

The alt text should be descriptive and concise matching the visual content of the image:
< img src="img.jpg"alt="jacket photo" >

The style Attribute

Applying inline styles to customize the visual apperance of HTML elements

Core Purpose

  • Inline Styling:Used to define style rules directly within a single element's tag.
  • Presentation:Quickly customize visual properties such as colors, fonts,margins,sizes and layout options.

Syntax & Example

Apply styles using the format property:value within the style attribute:
< p style="color:red;" >This is a red paragraph

The lang attribute

Declaring page language and regional country codes for browsers and search engines.

Core Purpose

  • Language Declaration:Include the lang attribute in the < html > tag to declare the langauge of the web pages to assist search engines abd browsers.
  • Country Codes:Extend languages codes with the regional variations(e.g first two characters for language,last two for country).

Syntax & Example

Specifying English as the language:
< html lang="en" >
Specifying English(US) as aregional variant:
< html lang="en-US" >

The title attribute

Defining auxiliary information about an HTML element that appears as a hover tooltip

Core Purpose

  • Tooltip Display:The value of the title attribute is typically displayed as a tooltip popup when the user hovers their mouse pointer over the element.
  • Extra Info:Used to provide advisory or extra helper information that doesnt need to be constantly visible on the page.

Syntax & Example

< p >Adding a tooltip to a paragraph element:
< p title="I'm a tooltip" > This is a paragraph< /p >

Always Quote Attribute Values

W3C recommendations and practical syntax requirements for quoting HTML doccument

W3C Recommendations

  • Standard:The HTML standard does not strictly require quotes around attribute values.
  • Best Practice:W3C strongly recommends quotes in HTML and demands them a stricter XHTML.
    •                 GOOD SYNTAX:
                < a href="https://www.itmbu.ac.in" >
                BAD SYNTAX(Avoid):
                < a href=https://www.itmbu.ac.in >

The space Exception

  • Space Limitation:Quotes are absolutely necessary when the attribute value contains space.Otherwise,it will not dispaly correctly.
  • SOCSET Standard:At SOCSET ,we always use quotes around attribute values to ensure clean and robust rendering.

Single or Double Quotes

Rules and standard for handiling nested quote marks inside HTML attributes

Standard Usage

  • Common Practice: Double quotes around attribute values are the most common in HTML,but single quotes can also be used.
    Standard Double Example:
    < p title="John Nelson" >
    Standard Single Quote Example:
    < p title='John Neslon'>

Handling Nested Quotes

  • The Conflict:When the attribute value itself conatins quotes,you must alternate quote styles to avoid breaking syntax.

    • Exaple:
    < p title="John 'Nelson'" >
    And vice-versa

Headings are important

Why and how to structure your web documents using HTML headings tags.

Best Practices

  • SEO & Indexing:Search engines use headings to index the structure and content of your web pages.
  • Readability:Users skim pages by heading. It is vital to use them to outline clear document.
  • Hierarchy:Use < h1 > for main titles,follwed by < h2 > for sections and < h3 > for sub sections.
