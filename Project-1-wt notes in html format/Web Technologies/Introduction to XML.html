Introduction to XML

XML (Extensible Markup Language) is a text-based markup language for representing, storing, and transporting structured data. Unlike HTML, which has a predefined set of tags for displaying a page, XML lets the author define descriptive tags that fit the data. XML describes what information means; another program or stylesheet decides how to use or display it.

For example, a course record can be represented as nested elements. The tag names— course , title , and credits —describe the values rather than their visual appearance. Because the document is plain text and has an explicit tree structure, different programs can exchange it without sharing the same internal data model.

Extensible

Authors choose meaningful element and attribute names for their domain; XML itself does not prescribe a fixed vocabulary.

Structured

Elements nest in a tree, allowing records to contain related subrecords in a clear parent- child relationship.

Portable text

XML can be read by people and processed by software on different platforms. It is a data format, not a programming language.

Well-formed versus valid

A well-formed XML document follows XML syntax rules: it has one root element, tags are properly nested and closed, and attribute values are quoted. A valid document is well-formed and also conforms to a declared grammar such as a DTD or XML Schema (XSD). A browser's XML parser can check basic well- formedness, but it does not automatically validate against every DTD or XSD.

Where XML is used

Exchanging structured data between applications and services.
Configuration files, document formats, and feeds such as RSS.
Representing data where explicit structure and human readability matter.
