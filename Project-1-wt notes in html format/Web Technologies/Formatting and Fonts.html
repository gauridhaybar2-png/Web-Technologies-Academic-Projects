HTML Display

How web browsers handle spaces,line breaks and responsive window reseizing.

Display Rules

  • Unpredictable Output:You cannot be sure exactly how HTML will be displayed ; screen sizes and resized windows create different results.
  • Code Spacing:Adding extra spaces or empty lines in your HTML code will not change how the content is rendered.
  • Automatic Clean-up:The browser automatically collapses multiple spaces and discards line breaks when rendering the page.

The HTML Style Attribute

Syntax and Structure of inline CSS styling in HTML elements

Style Basics

  • Inline Styling:
    • Setting the style of an HTML element is done directly inside the element tag using the style attribute.
  • CSS Declarations:
    • Each style declaration consists of a property and a value , separated by a colon and ending with a semicolon.
  • Style Precedence:
    • Inline styles override general styles defined in external stylesheets or style blocks.

Syntax & Blueprint

The standard format of the inline style attribute.

< tagname style=" property :value;" >

  • tagname:
    • The HTML element(e.g. p,h1,body)
  • property:
    • The CSS property you want to change (e.g.color)
  • value:
    • The value assigned to the CSS property(e.g. blue)
