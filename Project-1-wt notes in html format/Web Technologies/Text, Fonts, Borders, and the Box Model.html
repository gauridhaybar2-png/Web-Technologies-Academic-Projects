Text, Fonts, Borders, and the Box Model

Typography and Text

Font properties set the typeface, size, and weight. Text properties handle alignment and decoration. Relative sizes such as rem scale with the root font size; unitless line-height scales naturally with text.

Borders

A border needs a style such as solid or dashed to be visible. The shorthand border: 3px solid #174f78; sets width, style, and color together. One to four values can specify top, right, bottom, and left in that order.

Box Model

From the inside outward, an element consists of content, padding, border, and margin. Padding is inside the border; margin separates the outside of one element from its neighbors. With the default content-box sizing, a declared width applies only to the content; padding and border increase the rendered size. With border-box , the declared width includes content, padding, and border, which makes page layouts easier to calculate. Margins remain outside either box. In normal block flow, vertical margins of adjacent blocks can collapse into one margin rather than add together.

Default: content-box

For a 300px width, 20px horizontal padding, and 5px borders, the rendered width is 300px + 40px + 10px = 350px. Margins add outside

Predictable sizing: border-box

box-sizing: border-box includes padding and borders in the declared width. It is commonly applied globally.
