Colors and Backgrounds

CSS accepts named colors, hexadecimal notation, RGB, and HSL. Alpha variants such as RGBA control the transparency of the color itself without making child text translucent.Color can be applied to text with color and to an element's background with background-color . A background image or gradient is painted behind the content, so a fallback background color is helpful if an image cannot load. Choose text and background colors with sufficient contrast so content stays readable.
