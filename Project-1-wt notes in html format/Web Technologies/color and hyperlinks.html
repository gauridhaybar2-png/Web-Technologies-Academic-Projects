Color and Hyperlinks

An essential guide to text coloring and anchor elements in HTML

HTML Colors

HTML colors are specified with predefined color names, or with RGB, HEX, HSL, RGBA, or HSLA values.

Color Names

  • In HTML, a color can be specified by using a color name.
  • HTML supports 140 standard color names.

Color Values

Color Name: Tomato
RGB: rgb(255, 99, 71)
HEX: #ff6347
HSL: hsl(9, 100%, 64%)
RGBA: rgba(255, 99, 71, 0.5)
HSLA: hsla(9, 100%, 64%, 0.5)

Background Color

You can set the background color for HTML elements using the style attribute.

Code Example

Hello World

HTML Color Values

Using RGB, HEX, HSL, RGBA, and HSLA values to specify HTML colors.

Standard Color Values

  • RGB:
    • Defines a color using red, green, and blue values.
  • HEX:
    • Defines a color using a hexadecimal color code.
  • HSL:
    • Defines a color using hue, saturation, and lightness.

Translucent Color Values

  • RGBA:
    • RGB with an alpha channel for opacity.
  • HSLA:
    • HSL with an alpha channel for opacity. 
<h1 style="background-color:rgb(255, 99, 71);">...</h1>
<h1 style="background-color:#ff6347;">...</h1>
<h1 style="background-color:hsl(9, 100%, 64%);">...</h1>
<h1 style="background-color:rgba(255, 99, 71, 0.5);">...</h1>
<h1 style="background-color:hsla(9, 100%, 64%, 0.5);">...</h1>

HTML Links

Defining hyperlinks to connect web pages and navigate to external resources.

HTML Links - Syntax

The HTML <a> tag defines a hyperlink.

<a href="url">link text</a>
  • href Attribute:
    • Specifies the destination URL of the link.
  • Link Text:
    • The visible content displayed on the page.

Code Example

<a href="https://itmbu.ac.in">Visit itmbu.ac.in!</a>
Visit itmbu.ac.in!

HTML Links - The target Attribute

The target attribute specifies where to open the linked document.

Target Values

  • _self:
    • Default. Opens the document in the same window or tab.
  • _blank:
    • Opens the document in a new window or browser tab.
  • _parent:
    • Opens the document within the parent frame.
  • _top:
    • Opens the document in the full body window.

Code Example

<a href="https://itmbu.ac.in/"
target="_blank">
Visit itmbu.ac.in!
</a>
Visit itmbu.ac.in!

Absolute URLs vs. Relative URLs

Understanding how destination paths are defined in HTML anchor tags.

Absolute URLs

Uses a complete web address, including the protocol, to point to an external site or resource.

<a href="https://www.google.com">Google</a>

Relative URLs

Points to a page or folder within the current website, omitting the protocol and domain parts.

<a href="html_images.asp">HTML Images</a>
