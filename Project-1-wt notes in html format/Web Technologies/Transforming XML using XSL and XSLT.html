Transforming XML using XSL and XSLT

XSL (Extensible Stylesheet Language) is a family of technologies for working with XML. Its key parts include

XSLT (rules for transforming XML), XPath (expressions for selecting nodes and values), and XSL-FO (formatting objects, commonly used for paginated output). In many introductory materials, “XSL” is used informally to mean an XSLT stylesheet.

XSLT reads a source XML tree, selects nodes with XPath, and applies template rules to produce a result. The result can be HTML for a web page, another XML vocabulary, or plain text. XSLT changes the representation of data; it does not change the source XML.

Executable browser example

This workbench uses the browser's built-in DOMParser and XSLTProcessor . Edit the source XML or stylesheet, then run the transform. The included stylesheet selects each book and creates an HTML table.

What the stylesheet does

< xsl:template match="/"> begins at the document root.
< xsl:for-each select="catalog/book"> selects each book with an XPath expression and repeats the enclosed output.
< xsl:value-of select="@id"/> reads an attribute; selecting title or author reads an element's text. Literal HTML tags such as < table> become part of the result document.

Connect an XML file to a stylesheet

For a standalone XML file, an xml-stylesheet processing instruction can associate it with an XSLT file. Save the XML and XSLT files together and open the XML in a browser that supports this instruction. For a command-line demonstration, save the source as catalog.xml and the stylesheet from the workbench as catalog.xsl , then run xsltproc catalog.xsl catalog.xml . The transformed HTML is written to standard output; xsltproc is available with libxslt.
