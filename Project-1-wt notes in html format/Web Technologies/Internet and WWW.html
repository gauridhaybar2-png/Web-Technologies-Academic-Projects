Internet and WWW

The Internet is the global network of interconnected networks: hardware, links, routers, addressing, and protocols that move data between devices. The Web is one service that uses this network. Email, online games, file transfer, and voice calls can also use the Internet without being Web pages.

Internet: the infrastructure

IP addressing and routing deliver packets between networks. Transport protocols such as TCP or QUIC carry application traffic across connections.

Web: an application on it

Browsers use URLs, HTTP, HTML, and related technologies to request and display linked resources.

Analogy: The Internet is the road system; the Web is one kind of journey made using those roads. The roads carry many other kinds of traffic too.

From domain name to web page

1. The browser parses a URL and checks its cache and local configuration.

2. DNS resolves the host name to an IP address.

3. The browser establishes a connection to the server (and negotiates TLS for HTTPS).

4. It sends an HTTP request; the server returns an HTTP response.

5. The browser parses HTML, requests referenced resources, and renders the page.
